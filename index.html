“ ความหลงใหลในการเนรมิตจินตนาการ ให้กลายเป็นโมเดล 3 มิติที่จับต้องและมีปฏิสัมพันธ์ได้ในเกมจริง ”

สวัสดีครับ ผมเป็น 3D Artist และนักศึกษาพัฒนาเกม ที่ให้ความสำคัญกับทั้งด้านความสวยงาม (Aesthetics) และความถูกต้องทางเทคนิคของโมเดลเกม (Technical Game Topology)

มีความชำนาญในการขึ้นรูปโมเดลทั้ง Low-Poly และ High-Poly, การจัดระเบียบ Edge Flow เพื่อรองรับการ Rigging ข้อต่อ, การกางแผ่น UV ให้ใช้พื้นที่อย่างคุ้มค่า, การเพนต์ Texture สไตล์ Stylized Hand-painted และ PBR ใน Substance Painter รวมถึงการจัดฉาก แสง และเขียน Python Script เพื่อสร้างความสะดวกรวดเร็วในขั้นตอนผลิตเกม
